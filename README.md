## 免票规则要点

1. 凭本人深圳身份证 / 居住证 / 社保卡 / 户口本**原件**核验，仅限本人；
2. 只免**首道大门票**，观光车、索道、游船、温泉等二次消费自理；
3. 限流景区需提前在官方渠道实名预约「0 元门票」；
4. 深圳本地景区（世界之窗、欢乐谷等）**不参与**本轮免票。
